## 🌟 Overview

**SRI VIGNASEWRA SAREE HOUSE** is a modern, responsive, luxury e-commerce web application crafted specifically for traditional Indian ethnic wear businesses. Designed with a royal Indian color palette (Crimson Maroon, Zari Gold, Peacock Silk, and Raw Ivory), it showcases sarees, kurtas, dresses, lehengas, and gowns with an intuitive shopping experience.

---

## ✨ Key Features

- **👑 Royal Traditional Aesthetic:** Elegant typography featuring *Playfair Display* & *Cinzel*, festive gold borders, zari luster badges, and smooth animations.
- **🥻 Comprehensive Ethnic Catalog:**
  - **Sarees:** Kanchipuram Silk (Silk Mark certified), Banarasi Brocades, Chanderi Tissue, Flowy Georgettes, Organza Cutwork, and Pure Mulmul Daily Cottons.
  - **Kurtas & Suit Sets:** Flared Anarkalis with Dupattas, Straight Cut Sets, Alia-Cut Flared Kurtis, and Peplum Shararas.
  - **Dresses & Indo-Western:** Pre-draped Saree Gowns with Sheer Capes, Floor-length Anarkali Gowns, Boho Tiered Maxis, and Fusion Co-ord Sets.
  - **Bridal Ensembles:** Heavy Zardozi Velvet Bridal Lehengas and Banarasi Silk Lehengas.
- **🔍 Multi-Faceted Live Filtering & Search:**
  - Real-time search across names, fabrics, occasions, and categories.
  - Filter by Fabric (Mulberry Silk, Katan, Organza, Georgette, Cotton, etc.).
  - Filter by Occasion (Bridal, Festive & Puja, Cocktail Party, Daily Wear).
  - Price Range Slider (₹1,000 to ₹50,000).
  - Interactive Color Swatch Selector.
  - Quick Sort by Price, Customer Rating, or New Arrivals.
- **🛍️ Complete Shopping Cart & Wishlist System:**
  - Live quantity adjustment with instant subtotal and tax calculation.
  - Free Shipping Progress Bar (Free Pan-India Delivery on orders ₹1,999+).
  - Promo Code Applicator (e.g., `VIGNASEWRA20` for 20% off).
  - Wishlist toggle with persistent `localStorage` storage.
- **💬 Direct WhatsApp Commerce Integration:**
  - **1-Click WhatsApp Order:** Automatically formats selected products, sizes, quantities, and totals into an instant WhatsApp chat link to the store associate.
  - **Quick Item Inquiry:** Direct WhatsApp button on each product card for real-time video/photo inquiries.
  - **Video Call Shopping Booking:** Patrons can schedule live 1-on-1 WhatsApp video shopping sessions to view drape luster and silk folds in real-time.
- **🪡 Saree Draping & Style Assistant:**
  - Step-by-step interactive draping instructions for *Classic South Indian Nivi*, *Royal Bengali Atpoure*, *Seedha Gujarati Pallu*, and *Modern Belted Cocktail Drape*.
- **📍 Showroom & Trust Badges:**
  - Silk Mark certified authenticity assurance.
  - Flagship showroom address, operating hours, and customer care channels.
  - Real customer testimonials and verified bride reviews.
- **📱 100% Fully Responsive & Mobile Optimized:**
  - Smooth drawer menus, touch-friendly product cards, and responsive modals.

3. Keep it **Public** (or Private).
4. Click **Create repository**.

```powershell
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/sri-vignasewra-saree-house.git
git push -u origin main
```

*(Alternatively, if you use GitHub CLI `gh`:)*
```powershell

```

## 🌐 Deploy to GitHub Pages (Free Hosting)

Once pushed to GitHub, you can host it live for free in 30 seconds:
1. Open your repository on GitHub.
2. Go to **Settings** > **Pages** (under Code and automation).
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your website will be live at:  
   `https://<YOUR_GITHUB_USERNAME>.github.io/sri-vignasewra-saree-house/`
